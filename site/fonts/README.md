Commissioner by the Commissioner Project Authors: https://github.com/kosbarts/Commissioner

Licensed under SIL OFL 1.1; the full copyright and license notice is in `OFL.txt`.

This website uses a WOFF2 subset with the weight axis retained and other variation axes pinned at their upstream defaults. Included Unicode ranges: U+0000–024F, U+2000–206F, U+2190–21FF and U+20AC. System fallback handles other scripts. Prepared using fontTools 4.65.0. This preserves the normal upright appearance while avoiding downloading unused character ranges and variation axes.
